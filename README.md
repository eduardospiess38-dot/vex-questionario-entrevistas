# VEX — Questionário de Entrevistas

Aplicação estática publicada via GitHub Pages para coleta estruturada de informações sobre uso de sistemas, dificuldades, melhorias e requisitos úteis para desenvolvimento.

## Recursos

- formulário multi-etapas;
- perguntas abertas com espaço para escrita;
- acessibilidade com alto contraste e redução de movimento;
- dashboard anônimo com dados agregados;
- exportação CSV agregada;
- identidade visual VEX com logo oficial.

## Estrutura

- `index.html` — questionário;
- `admin.html` — dashboard anônimo;
- `styles.css` — interface visual;
- `app.js` — fluxo do formulário;
- `admin.js` — renderização do dashboard;
- `static-store.js` — armazenamento local e classificação das respostas;
- `assets/vex-logo.svg` — logo oficial.

## GitHub Pages

A aplicação é estática e compatível com publicação direta em GitHub Pages pela branch `main`, pasta `/`.
